# Hero background videos

Drop a short, muted, looping MP4 here. The Saturday Command hero looks for:

1. `hero-repo.mp4` when Game of the Week is R.E.P.O.
2. `hero-<slug>.mp4` for other games (letters/digits only, lowercased)
3. `hero.mp4` as a generic fallback

Do not commit copyrighted full gameplay. Prefer a few-second royalty-free or self-captured loop.
If no file is present, the hero uses the Steam header poster plus a canvas ambient (R.E.P.O.).
